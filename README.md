Hands-on cybersecurity lab exploring PDF password cracking using John the Ripper (JTR), Johnny GUI, and Networkwalks Web Tools.
🔐 Week 3: Password Cracking Lab

📌 Overview

This repository documents my Week 3 cybersecurity lab, where I explored PDF password cracking using both offline and online tools.

🛠️ Tools Used

1. John the Ripper (JTR) & Johnny GUI – Offline password cracking.
2. Networkwalks Web Tools – Online Hash Calculator and Password Cracker.

🎯 Objectives

* Understand password hashing.
* Explore password-cracking techniques.
* Practice using cybersecurity tools.
* Troubleshoot Windows DLL errors.
* Understand the risks of weak passwords.

💡 Key Takeaway

Hashing is a one-way process, but weak passwords can still be discovered through brute-force and dictionary attacks.

📚 Lessons Learned

Strong, unique passwords are essential for protecting sensitive information against password-cracking attacks.
